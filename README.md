# 🐍 Automatización y Análisis con Python

Este repositorio contiene scripts creados en Python para la automatización de procesos operativos (generación de reportes estructurados) y el Análisis Exploratorio de Datos (EDA) con visualizaciones interactivas.

---

## 📁 Estructura del Repositorio

```text
automatizacion-y-analisis-python/
├── scripts/
│   ├── script_reportes.py       # Automatización de reportes ejecutivos en Excel
│   └── analisis_datos.py        # Análisis de tendencias e indicadores con Plotly
├── .gitignore                   # Filtro de archivos temporales
├── requirements.txt             # Librerías necesarias para el proyecto
└── README.md                    # Documentación del repositorio
